# Backend Python — código demonstrativo

Estes módulos foram extraídos do projeto real para apresentar as competências técnicas utilizadas no POST MORTEM.

- `planner_engine.py`: distribuição de estudos, prioridades e disponibilidade.
- `program_parser.py`: identificação estruturada de disciplinas e subitens do edital.
- `ai_extract.py`: extração assistida por IA e tratamento de conteúdo PDF.
- `pdf_maker.py`: geração de PDFs interativos com ReportLab.

**Não é uma API comercial pronta para execução.** Não inclui `main.py`, `commercial.py`, integrações de pagamentos, autenticação, banco de dados nem configuração de produção. As dependências e variáveis de ambiente são gerenciadas no projeto privado.

O projeto oficial está disponível em https://postmorrtem.netlify.app/.
