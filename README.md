# POST MORTEM | Dissecando o edital

**Plataforma educacional e ferramentas digitais para preparação em concursos policiais.**

O POST MORTEM é um projeto que une tecnologia e educação para facilitar a organização dos estudos e oferecer recursos personalizados aos candidatos de carreiras policiais.

## Funcionalidades

- **Gerador de cronogramas personalizados:** planejamento adaptado ao concurso, cargo, disponibilidade e preferências de estudo.
- **Inteligência artificial:** identificação de disciplinas e conteúdos programáticos a partir de editais em PDF.
- **Cronogramas interativos:** arquivos em PDF com acompanhamento de atividades e progresso.
- **Materiais educacionais:** guias interativos, flashcards e conteúdos voltados à preparação policial.
- **Plataforma comercial:** integração com serviços de pagamento, autenticação e gerenciamento de créditos.

## Tecnologias

- HTML, CSS e JavaScript
- Python e FastAPI
- Google Gemini API
- Supabase
- Netlify e Render
